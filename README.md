# نسخة المختبر — سيف تداول

نسخة تجريبية كاملة من منصة سيف تداول. **ليست المنصة الحقيقية.**

- المنصة الحقيقية: https://ideas-pipeline.github.io/stocks/
- هذه النسخة للتجارب فقط — أي تعديل هنا لا يمس الإنتاج

## البناء

بعد أي تعديل على `template.html`:

```bash
python3 build.py
```

يبني `index.html` بحقن `stocks-data.json` مكان `__STOCKS_DATA__`.

## القواعد

1. لا تشغّل سكربتات `scripts/` — تحتاج مفتاح سهمك وسيرفر الإنتاج
2. `stocks-data.json` يُحدَّث من السيرفر تلقائياً — لا تعدّله يدوياً
3. الأسرار ممنوعة: لا تضف أي مفتاح أو توكن لهذا المستودع
